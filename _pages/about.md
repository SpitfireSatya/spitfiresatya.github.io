I'm an Applied Scientist at Amazon Web Services, where I work in one of the automated reasoning groups on providing correctness guarantees for code migrations. Before this, I was part of the Agentic AI organization, combining traditional program analysis techniques with AI agents to carry out code migrations.

I earned my PhD in Computer Science from Northeastern University, advised by Frank Tip. My work sits at the intersection of Programming Languages and Software Engineering, with a research focus on Declarative Software Rewriting: a technique for automatically improving the performance and security of web applications. I also hold a Master's in Cybersecurity from Northeastern, with interests in secure software development, penetration testing, and risk management.

Earlier in my career, I spent close to four years as a web software developer at Tata Consultancy Services, working on digital transformation projects in Agile settings and serving as a code auditor, an experience that shaped my focus on code quality and drew me toward software security.
