I'm an Applied Scientist at Amazon Web Services, where I work in one of the automated reasoning groups on providing correctness guarantees for code migrations. Before this, I was part of the Agentic AI organization, combining traditional program analysis techniques with AI agents to carry out code migrations.

I earned my PhD in Computer Science from Northeastern University, advised by Frank Tip. My work sits at the intersection of Programming Languages and Software Engineering, with a research focus on Declarative Software Rewriting: a technique for automatically improving the performance and security of web applications. Before research, I spent close to four years as a web developer and code auditor at Tata Consultancy Services, which drew me toward software security.

**If you're interested in working with me, I'd love to hear from you, please feel free to [reach out](mailto:satyagokhale@acm.org).**
